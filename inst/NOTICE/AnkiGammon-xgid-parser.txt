backgammonboard contains an independently authored native R behavioral port of
selected XGID decoding behavior. The pinned implementation was used to verify
field meaning, turn-relative checker decoding, bar ordering, checker-case
interpretation, cube metadata, action markers, raw scores, match metadata, and
maximum-cube metadata.

The R package deliberately applies stricter validation than the reference where
required by the backgammonboard contract. It accepts only complete supported
XGIDs, rejects unsupported B and R action markers, rejects impossible checker
totals, and enforces the package-supported factual cube limit of 64.

No AnkiGammon Python source code is bundled, no Python runtime or package is
required, and package tests consume only static fixture data. The full upstream
MIT license is retained in inst/COPYRIGHTS.
