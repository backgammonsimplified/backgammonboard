# Checker move illustration gallery

This gallery is generated by `dev/render-move-illustration-gallery.R`. Each SVG
shows the resulting checker position, a translucent ghost at every moved
checker origin, and the move path. The factual input position remains available
on the plot as `backgammon_position`; the rendered result is available as
`backgammon_display_position`.

| Asset | Contract exercised |
| --- | --- |
| `ordinary.svg` | Ordinary move plus optional board text |
| `hit.svg` | Hit marker and opponent checker moved to the bar |
| `bar_entry.svg` | Checker leaves the bar and enters on a point |
| `bearing_off.svg` | Checker moves to the off tray |
| `reversed.svg` | Black perspective and reversed board geometry |

The gallery is deterministic for a fixed R and graphics stack. Regenerate it
from the repository root; do not hand-edit the SVGs.
