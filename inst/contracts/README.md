# Contract index

The current release contract is version 1.1, summarized by the package README
and `DESCRIPTION` metadata. Existing named contract documents in this folder
are retained as historical implementation records. In particular,
RendererPosition, source move-notation parsing, GNU/AnkiGammon conversion, and
legacy cube-context documents describe deferred or superseded paths and are not
part of the v1.1 public API.

Historical records are kept to explain prior fixtures and reviewed geometry;
they must not be used to broaden accepted release inputs.
