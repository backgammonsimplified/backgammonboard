backgammonboard contains an independently authored native R behavioral port of
selected move-notation behavior. The pinned implementation and direct tests were
used as a behavioral reference and fixture oracle.

The R implementation deliberately preserves local contract fields that the
reference does not expose, including ordered step identifiers, checker-chain
identifiers, original normalized source tokens, explicit hit-marker claims, and
repetition-group identifiers. It also returns structured token-specific errors
rather than silently skipping malformed components.

No AnkiGammon Python source code is bundled, no line-by-line translation was
performed, and no Python runtime or package dependency is introduced.

The full upstream MIT license is retained in inst/COPYRIGHTS. Any source-derived
fixture must be identified separately from independently authored fixtures.
